# Processed E-commerce Dataset 

## Project Overview
 The objective is to create a clean and meaningful processed e-commerce dataset by combining and transforming information from three separate CSV datasets: Orders, Customers, and Products.

The project is implemented using Python and Pandas in Google Colab.

## Datasets

The project uses the following input datasets:

- `Orders.csv` — Contains order and transaction information.
- `Customers.csv` — Contains customer-related information.
- `Products.csv` — Contains product-related information.

## Technologies Used

- Python
- Pandas
- Google Colab
- GitHub
